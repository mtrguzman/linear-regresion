House Price Prediction Demo

A simple machine learning project demonstrating end‑to‑end model training and deployment.

About This Project

This project showcases a complete machine learning workflow built from scratch:

  • Understanding and preparing a dataset of house sizes and prices
  • Implementing a linear regression model
  • Training the model to learn the relationship between size and price
  • Deploying the trained model using an API
  • Building a public webpage that interacts with the API

The goal is to demonstrate how a simple idea can be turned into a fully deployed, interactive ML application. This page serves as the public interface where you can test the model in real time.

Project Workflow

This demonstration is built using a very small dataset of six properties. Each entry contains two values: the size of the house (in square feet) and its selling price. The dataset used to train the model is shown below:

Because this dataset is small and contains only one variable (house size), a linear regression model is an appropriate choice. Linear regression works well when the relationship between variables is simple and roughly linear.

In real-world scenarios, datasets are much larger and include many more features such as number of bedrooms, location, age of the property, and market conditions. Larger and more complex datasets often require more advanced models (e.g., decision trees, random forests, gradient boosting, or neural networks). Generally, the more data you have, the more accurate and reliable the model becomes.

During training, the model calculates how strongly the house size influences the price. These learned values are called weights. Once training is complete, the weights are saved and used by the API.

The API loads the trained weights and uses them to predict the price of a house based on a size value provided by the user. This webpage connects to that API: when you enter a house size below, the API returns the predicted price for that unseen input.

Technologies Used

  • Python — model implementation and training
  • NumPy — numerical operations
  • FastAPI — serving predictions via an API
  • GitHub Pages — hosting this webpage
  • JavaScript — connecting the frontend to the API
